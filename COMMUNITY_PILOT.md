# OSS maintainer pilot program — start with real users

AgentFlow Runtime is an experimental, trusted, local-first task workflow manager for developer automation. We need real maintainer feedback before calling it production-ready.

## Proposed two-week pilot

1. Invite 3–5 maintainers to run a **local Echo-only demo**, not autonomous source edits.
2. Ask each to follow README and NATIVE_BUILDS instructions; note the host OS, Python version, install friction, and any errors.
3. Collect one example of a real maintenance workflow where durable queueing, cancellation or human approval matters.
4. Ask participants to open public GitHub Issues or PRs voluntarily. Do not purchase or fabricate stars/downloads/reviews.
5. Report only verifiable feedback, issues, merged PRs, and repeat usage; do not claim adoption before evidence exists.

## Public issue prompts

- Installation/compatibility bug (include redacted logs and OS/version)
- Feature request (real maintainer use case, not a speculative integration)
- Security concern (report privately per SECURITY.md)
- Documentation correction or minimal example

No data collection, external account login or API spend is required for the demo.
