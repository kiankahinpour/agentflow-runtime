# Community Code of Conduct

AgentFlow Runtime aims to be a respectful, technically rigorous, and inclusive open-source project.

## Expected behavior

- Discuss code and evidence rather than attacking people.
- Be constructive and patient with questions and reviews.
- Welcome contributors with different experience levels and backgrounds.
- Respect privacy, intellectual property, and responsible disclosure.
- Accept maintainer decisions about scope, risk, and release readiness.

## Unacceptable behavior

Harassment, discriminatory language, threats, personal attacks, doxxing, unwanted sexual attention, or publishing private data are not acceptable in project spaces.

## Moderation

Maintainers may edit or hide inappropriate content, close threads, decline contributions, or block accounts when needed. If you need to raise a sensitive conduct concern, request a private contact channel from a maintainer without including private details in a public issue. A staffed confidential reporting channel and response-time SLA have not yet been established.

This policy covers project issue discussions, pull requests, reviews, and maintainer-operated project spaces. For security vulnerabilities, use the separate [security policy](SECURITY.md).
